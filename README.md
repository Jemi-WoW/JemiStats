# JemiStats

![JemiStats](https://raw.githubusercontent.com/Jemi-WoW/JemiStats/main/externals/img/jsScreenshot1.png)

Tracks what your character actually did — every kill, crit, close call and zone. Live, per character, saved between sessions.

Runs on **Classic Era**, **Burning Crusade Classic** and **WoW Forever** (beta).

## Features

- **On-screen window** — pick the stats you want visible, drag it anywhere
- **Toasts** — pop-ups when a stat goes up, with three noise levels
- **~60 stats** — survival, combat, exploration, class, professions, economy, questing, habits
- **Deaths and what killed you** — reads the same on Hardcore or normal
- **Works with [Oathbound](https://www.curseforge.com/wow/addons/oathbound)**

## Using it

`/jstats` to open. Right click the on-screen window for stats, shift + right click for settings.

`/jstats help` lists the rest.

**Upgrading from Oathbound?** Your records import automatically — just keep Oathbound installed for that first login.
